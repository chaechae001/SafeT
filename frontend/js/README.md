# 화면 동작과 API 호출

공통 API 호출은 `api.js`, 화면별 동작은 `basic.js`처럼 화면 이름으로 구분합니다.

- API 주소·오류 처리는 공통 파일에서 관리합니다.
- API 키·DB 비밀번호를 프런트엔드에 넣지 않습니다.
- 입력 단계 간 상태와 실제 DB 저장을 구분합니다.
- 실제 JavaScript 파일은 화면 뼈대 구현 때 추가합니다.

## jQuery 연결 (2026-11-16 추가)

jQuery 3.7.1을 `vendor/jquery-3.7.1.min.js`에 로컬 파일로 두었습니다(인터넷 없이도 동작). SHA-256 `FC9A93DD…F0B1A`로 공식 배포본과 같은지 확인했습니다.
각 화면은 `jquery → common.js → 화면 JS` 순서로 불러옵니다.

### 공통 사용법 (`window.SafeT`)

- `SafeT.go('v-risk', opts)`: 같은 파일 안의 화면으로 이동합니다. 도착한 화면에 `safet:show` 이벤트로 `opts`가 전달됩니다.
- `SafeT.openModal('confirm')` / `SafeT.closeModal()`: 확인 창을 열고 닫습니다. `[data-close]`·Esc·바깥 클릭으로도 닫힙니다.
- `SafeT.confirm({ title, message, ok, cancel, alt })`: 브라우저 `confirm()` 대신 쓰는 확인 창입니다.
- 폼 제출: `required`·이메일·`minlength`·날짜 형식을 검사합니다. 화면별 추가 검사는 `safet:validate`, 제출 처리는 `safet:submit` 이벤트에서 합니다.
- `SafeT.toast()`, `SafeT.loading(true|false)`, `SafeT.runProgress()`: 알림, 원형 로딩(데이터만 저장), 진행률(AI 판단 포함)을 표시합니다.
- `[data-todo="안내 문구"]`: 아직 API가 없는 버튼에 붙이면 누를 때 안내 문구가 뜹니다.

### 아직 API 연결 전인 부분

- 화면의 평가표·사업장·위험 항목은 각 JS 파일 위쪽의 합성 예시 데이터입니다. 새로 고침하면 처음 상태로 돌아갑니다.
- 저장·AI 판단·진행률은 일정 시간 뒤 완료되는 데모입니다. API를 연결하면 서버 응답 시점에 맞춥니다.
- 판단 필요 항목의 '다시 판단'은 "예시 결과"라고 표시된 데모 값으로 채웁니다. 실제 AI 판단이 아닙니다.
- 음성 녹음, 엑셀·PDF 다운로드, 비밀번호 재설정, 공유 링크 재발급은 안내 문구만 띄웁니다.

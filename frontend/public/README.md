# 공용 이미지

공유 가능한 로고·아이콘·일러스트를 둡니다. 현재 HTML 개발의 공용 이미지 경로입니다.

- 이 경로의 PNG·JPG·JPEG·WEBP는 `.gitignore` 예외로 허용됩니다. SVG·ICO도 현재 차단되지 않습니다.
- 필요하면 `images/`, `icons/`를 추가합니다.
- 실제 현장 사진·사용자 업로드·식별 가능한 이미지는 넣지 않습니다.
- `frontend/src/assets/`도 허용되지만 두 경로를 모두 만들 필요는 없습니다.
- `public/`이라는 이름만으로 URL이 자동 연결되지 않습니다. HTML·서버 설정에 맞춰 경로를 지정합니다.

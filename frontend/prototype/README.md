# Safe-T 프로토타입 v3.19

소규모 사업장 위험성평가의 화면·사용 흐름을 확인하는 프로토타입입니다.

[웹 프로토타입](https://safet-spec-311-1114.chaeeun1208.chatgpt.site) — 접속 권한이 있는 계정으로 열 수 있습니다.

## 실행

저장소 루트에서 실행한 뒤 http://localhost:8080 을 엽니다.

```bash
python -m http.server 8080 --bind 127.0.0.1 --directory frontend/prototype
```

HTML 파일을 직접 더블클릭하지 말고 위 주소로 접속합니다.

## 사용 순서

1. 회원가입 → 인증 요청 → 화면에 표시되는 시연 코드 입력
2. 사업장과 보유 기기 등록
3. 새 평가표 → 기본정보 → 현장 설명 → 기기 확인
4. 현재 안전조치·개선대책 선택 → 담당자·예정일 일괄 지정
5. 평가표 저장 → 확정 → 참여자 직접 서명
6. Excel·PDF 출력, 공유 화면 확인

## 시연 범위

- 이메일 발송·AI 분석은 연결 전이며 치킨점 예시를 사용합니다.
- 입력과 서명은 각자의 브라우저에만 저장됩니다. 다른 팀원의 입력은 보이지 않습니다.
- 평가표 공유 링크는 같은 브라우저의 수신자 화면 시연용입니다.
- 후속업무는 확정본을 연 뒤 상단 ‘검토 안내’에서 확인합니다.
- 안내 이미지는 공개용 촬영 구도 도식입니다. 실제 현장 사진은 포함하지 않습니다.

`app.js`는 화면·상태, `app.css`는 스타일, `xlsx.js`는 Excel 출력을 담당합니다.

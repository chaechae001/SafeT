# 프런트엔드

상태: HTML·CSS·JavaScript 화면 개발을 위한 폴더와 안내만 준비했습니다. 실행 가능한 화면은 후속 작업입니다.

| 경로 | 역할 |
|---|---|
| [pages/](pages/README.md) | 기능별 HTML 화면 |
| [css/](css/README.md) | 공통·화면별 스타일 |
| [js/](js/README.md) | 화면 동작·API 호출 |
| [public/](public/README.md) | 로고·아이콘·공용 이미지 |

먼저 전체 화면 이동·공통 UI·합성 데이터 표시를 구현합니다. 파일 이름은 `basic.html`, `basic.css`, `basic.js`처럼 맞춥니다.
실제 HTML이 아직 없으므로 현재 실행 명령은 없습니다. 화면 뼈대 PR에 실행 방법을 추가합니다.

서비스 데이터 저장과 권한 검사는 백엔드에서 수행합니다.
AI 추천값과 사용자가 선택한 값을 구분하며, 정보 부족을 낮은 위험으로 표시하지 않습니다.
API 연결 전에 [공통 JSON](../contracts/README.md)을 맞춥니다.
공통 CSS·API 호출 코드 변경은 작업자와 먼저 조율하고, 세부 담당자는 Issue에서 정합니다.

## 화면 뼈대 추가 (2026-11-16)

화면설계서 v3.19 통합본과 테이블 정의서 V1.1을 기준으로 HTML·CSS 화면 뼈대를 추가했습니다. JavaScript 동작과 API 연결은 후속 작업입니다.

### 실행 방법

빌드 없이 브라우저로 엽니다. 시작 화면은 `pages/login.html`입니다.

```bash
# 저장소 루트에서 실행 후 http://localhost:8000/pages/login.html 접속
python -m http.server 8000 --directory frontend
```

`pages/*.html` 파일을 더블클릭해 열어도 됩니다.

### 구성

- jQuery 사용을 전제로, 한 흐름의 화면은 HTML 한 파일 안에 `<section class="view">`로 나눠 넣었습니다(10개 파일).
- 처음 보이는 화면에는 `.is-active`가 붙어 있습니다. 화면 전환은 jQuery로 `.is-active`를 옮기면 됩니다.
- JS 없이 확인할 때는 주소 끝에 `#view-id`(예: `draft.html#v-bulk`)를 붙이면 그 화면이 보입니다.
- 확인 창은 `.modal`입니다. jQuery로 열 때는 `.is-open`을 붙입니다. JS 없이는 `#창-id`로 열립니다.
- 메뉴는 `<details>`, 초록 항목 탭·담당자 토글은 라디오와 `:has()`로 동작합니다.
- 입력값은 저장되지 않습니다. 화면에 보이는 사업장·사람·위험 항목은 모두 합성 예시이며 실제 판정이 아닙니다.
- 각 화면 위 주석에 화면설계서 쪽수와 관련 테이블·컬럼을 적었습니다.

## jQuery 연결 (2026-11-16 추가)

- 화면 동작을 jQuery 3.7.1로 연결했습니다. 파일별 역할과 공통 사용법은 [js/README.md](js/README.md)에 있습니다.
- 실행 방법은 위와 같습니다. jQuery는 `js/vendor/`에 로컬 파일로 있어 따로 설치하지 않습니다.
- 데이터는 합성 예시이고 저장·AI 판단은 데모입니다. 새로 고침하면 처음 상태로 돌아갑니다.
- 동작 확인: 헤드리스 크롬(Selenium)으로 화면 10개를 눌러 보는 검사 104개를 통과했습니다(2026-11-16). 검사 스크립트는 저장소에 넣지 않았습니다.

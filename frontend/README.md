# 프런트엔드

상태: 안내만 준비했다. 실행할 애플리케이션과 확정 기술 스택은 없다.

담당 범위 초안:
- 사진·작업 설명 입력과 분석 상태 표시.
- 관찰 내용, 위험유형 후보, 근거와 정보 부족 항목 표시.
- 사용자의 검토·수정과 개선 이력 화면.

서비스 데이터 저장과 권한 검사는 백엔드에서 수행한다.
AI 결과와 사람이 확인한 결과를 구분해서 표시한다.
미평가·정보 부족 상태를 낮은 위험으로 표시하지 않는다.

연결 전 [데이터 형식 초안](../contracts/README.md)을 팀과 확정한다.
실제 코드를 추가할 때 실행 명령, 의존성과 필요한 환경변수를 이 문서에 기록한다.

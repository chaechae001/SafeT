| 음성 3단계 | 대기 `[● 녹음][■ 중지]…[초기화]` → 녹음 중 `● 00:18 녹음 중`·`[일시정지][중지(빨강)]`·실시간 변환 중 문장 → 완료 `00:24 녹음 완료`·▶ 재생 막대·`[재녹음][초기화]`·변환된 텍스트(고칠 수 있음) | ✅ (실제 마이크 미확인) |
| 텍스트 | 입력 중 딥그린 테두리, `n / 500` 글자 수, 하단 안내 문구 | ✅ |
| 현장 기록 가이드 | 가운데 둥근 창(뒤 어둡게), 2×2 촬영 카드, 노란 안전 경고, 음성·텍스트 팁, `확인했어요` — 휴대폰 한 화면 | ✅ |
| 05 목록 위험도·상태 | 위험도는 글자 없는 3구 신호등(모든 화면 연회색 몸체), 미작성 = 흰 바탕 진한 테두리 + 할 일 버튼 모양, 임시저장 = 점선 + 회색 배지, 작성 완료 = 연회색으로 톤다운 | ✅ |
| 05 목록 삭제 | `편집` → `✓ 완료`, 카드마다 연한 빨강 휴지통. 휴대폰은 카드를 왼쪽으로 밀면 빨간 `삭제` | ✅ (실기기 밀기 미확인) |
| 05 상세 | 신호등, 현재 하고 있는 조치는 개선대책에서 회색 + `현재 조치 중`, 긴 안내 대신 `예상 위험도 분석` 카드(현재 → 개선 후, 남은 필수 조치 강조) | ✅ |
| 담당자·예정일 기본값 | 대책을 고르면 담당자 = 평가담당자(작성자), 예정일 = 작성일이 자동으로 들어감. 지정 창에 작성자도 표시 | ✅ |
| 03 내 평가표 | 기간 한 칸(`2026.11.01 ~ 2026.11.22` + 달력), 회색 검색 상자, 작성 중 = 점선 + `이어서 작성하기`, 확정 = `서명하기`·`문서 다운로드`, 서명 완료 = 회색 + `문서 다운로드`, `+ 새 평가표` | ✅ |
| 06 확정 화면 | `확정` + `🔒 읽기 전용(수정 불가)` 배지, 기본 정보 2열 회색 상자, 라벨 열 정렬, 담당·예정은 구분선 아래 | ✅ |

※ 서명 완료 카드의 `결과 공유`는 공유 화면으로 가는 유일한 입구라 작은 링크로 남겼습니다. 위험 항목 수는 목록 서버 응답에 없어 카드에 넣지 않았습니다.

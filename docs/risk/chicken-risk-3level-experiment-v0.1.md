# 치킨집 3단계 위험도 판단 기준 — 실험안

버전 `CHK-3L-EXP-0.1`. 기존 CHK-3L-1.0 문서를 참고한 실행 실험이며 검증된 공식 기준으로 대체하지 않습니다. 법령이 모든 음식점 위험에 고정된 상·중·하 등급을 지정한 것은 아닙니다. 아래는 공단의 3단계 설명을 바탕으로 팀이 시험하는 운영 정의입니다.

## 현재와 예상의 차이

| 구분 | 판정에 넣을 상태 | 결과의 의미 |
|---|---|---|
| 현재 위험도 | 지금 시행 중이고 효과를 확인한 조치와 실제 작업 조건 | 현재 상태의 후보 등급 |
| 개선 후 예상 | 구체적인 계획이 명시한 조건대로 작동한다는 검토된 가정 | 미실행·조건부 예측, 안전 확보 증명 아님 |
| 개선 후 실제 | 실행 및 효과 확인 이후 현장 상태 | 새로 평가해야 하는 값; 이 실험은 계산하지 않음 |

기기의 종류만으로 등급을 고정하지 않습니다. 작업·위험 경로·노출·현재 통제를 함께 확인합니다. 예를 들어 튀김기가 있다는 이유만으로 무조건 상이 아니며, 장갑 지급만으로 자동 하향하지 않습니다.

## 우선순위 규칙

| 순서 | 조건 | 출력 |
|---|---|---|
| 1 | 해당 작업에 적용됨을 확인한 법정조치 미이행 | 상(R) |
| 2 | 조치를 고려해도 사망·영구장해로 이어질 잔여 위험 경로 존재 | 상(R) |
| 3 | 위 상 조건이 확인되지 않았으나 핵심 정보·조치효과·법 적용 확인 부족 | 판단 필요(N) |
| 4 | 치료가 필요한 부상·질병 가능, 미해결 아차사고, 또는 부분적/무효 통제 중 하나 이상 | 중(Y) |
| 5 | 정보가 충분하고 위 조건이 모두 없으며 유효한 통제 또는 통제 불필요 근거 확인 | 하(G) |

N은 네 번째 위험등급이 아닙니다. 상 조건을 이미 확인한 경우 나머지 정보 부족이 상 표시를 지우지 않습니다. 상·중의 개선 우선순위를 정하고 하에서도 통제를 유지합니다. 급박한 위험은 등급 계산 완료를 기다려 작업을 계속하는 근거로 삼지 않습니다.

현재 조치가 위험 경로를 실제로 통제하는지 판단해야 하며, 단순히 '사망할 수도 있다'는 최대 피해 상상만으로 모든 작업을 상으로 만들지 않습니다. 반대로 보호구·교육 실시 사실만으로 중대 위험 해소를 단정하지 않습니다.

## 예상등급 하향 조건

현재와 **동일한 규칙**을 가정된 상태에 적용합니다. 대책, 작동 가정, 효과 이유, 실행 후 확인 절차와 효과 검토가 모두 필요합니다. 사라진 위험 플래그마다 대책 연결이 있어야 합니다. 현재 핵심 정보가 미확인이라 N이면 이를 예상 하로 덮지 않습니다. 예상 상태에서 중대 위험이 확인되면 상 경고를 표시할 수 있습니다.

등급은 상→중, 중→하, 상→하 모두 가능하나 그 차이를 설명해야 합니다. 같은 등급 유지나 악화도 가능합니다. '대책 3개면 한 단계 하향'과 같은 점수 규칙을 쓰지 않습니다. 실제 조치 효과가 확인되기 전에는 예상 하를 작업 허용이나 개선 완료로 사용하지 않습니다.

## 사례와 검증 범위

[15개 합성 사례](../../ai/risk_rules/examples.json): 폐유 이송 상→중, 장갑만 추가 상→상, 배수 개선 중→하(강한 효과 가정), 가스 사진 정보 부족 N→N, 법정조치 해소 상→하(적용·효과 확인 가정), 새로운 위험 유발 중→상 등을 포함합니다. 실제 사고 조사나 전문가 판정 데이터가 아닙니다.

표준 사례에서 규칙 일관성을 검사한 뒤, 팀이 서로 결과를 보지 않고 실제 익명 사례를 판정하고 차이의 이유를 기록해야 합니다. 자동 판정 정확도 검증은 아직 수행하지 않았습니다. 최종 확정·검토자·법령 근거 저장 및 화면/API 연결은 후속 작업입니다.

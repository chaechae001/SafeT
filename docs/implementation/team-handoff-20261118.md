# 역할별 연결 사항

현재·예상 위험도와 AI 초안을 통합한 검토용 PR이다. 실제 AI 전체 흐름은 서버 복구 후 검증한다.

| 영역 | 확인할 내용 |
|---|---|
| 초안·계산 | AI는 후보·근거·질문을 제안하고 등급은 공통 기준으로 계산 |
| 저장 | 현재 조치 전체 확인 값 controls_reviewed 전달. 정보 부족은 확정 차단 |
| 개선대책 | 저장 후 예상 위험도를 별도 표시. 현재 위험도나 실제 완료 상태와 구분 |
| 질문 답변 | answers에 item_id 필요. additional_text 제거. 화면·API 동시 반영 |
| 삭제·휴지통 | PR #24 통합. 복원 후 AI 근거와 현재·예상 결과 보존 |
| DB·범위 | 새 테이블·열 없음. 구 1.0 자료는 조회만 가능. 부록 37–41쪽 제외 |

## 분담

- AI·계산: 서버 복구 후 텍스트 초안·답변 재분석·SAM 사진 연결 검증.
- 화면·문서: PDF 현재/예상 표기와 한글 표시, 서명·공유·휴대폰 QR 검수.
- AI 서버: EXAONE·SAM 실행 상태, 공개 주소와 인증 확인.

초안 화면과 평가표 저장 API가 공통 수정 영역이므로 병렬 수정 시 변경 내용을 먼저 공유한다. AI 서버 없이 화면을 검사할 때는 별도 DB 설정 후 --catalog 모드를 명시적으로 사용한다. AI 실패 시 자동 전환하지 않는다.

## 검증 상태

로컬 자동 테스트 155개, 브라우저 오류 후 재시도·삭제·복원·확정·영구 삭제, CPU 검사 3종 통과. 실제 모델의 반복 질문 개선과 전체 흐름은 아직 미검증이다.

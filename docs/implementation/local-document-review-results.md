# 로컬 문서·서명·공유 검수 결과

검수일: 2026-11-18. 현재 통합 폴더와 전용 DB `safet_local_review`에서 실행했습니다.
실제 AI는 차단한 `catalog_v1` 모드이며, 모든 참여자와 서명은 합성 검수 자료입니다.
커밋·푸시하지 않았습니다.

| 관련 회귀 테스트 | 별도 테스트 DB에서 PDF·서명·공유 21개 통과 |
| 저장소 필수 검사 | CPU 자체 검사 3개 및 contracts JSON 검사 통과 |

최초 준비된 평가표 1647에는 참여자가 없어 확정·PDF 검사에 사용했습니다.
참여자 2명이 있는 별도 평가표 1649로 서명·공유를 검사했습니다. 제품 코드 오류는 발견하지 못했습니다.
검사 스크립트는 현재 조치를 먼저 저장한 뒤 개선대책을 입력하고, QR 보기 팝업을 여는 실제 화면 순서에 맞춰 조정했습니다.

로그인 후 결과: http://localhost:8000/pages/result.html?eval=1649
로그인 후 공유 관리: http://localhost:8000/pages/share.html?eval=1649
검수 산출물은 Git 제외 폴더 `.venv`의 `review-owner.pdf`, `review-public.pdf`, `review-share.png`에 있습니다.

## 처음부터 끝까지 남은 검수

1. 회원가입·인증메일·비밀번호 재설정: 실제 메일 설정 및 수신함 검증. 현재 계정은 준비된 검수 계정입니다.
2. 사업장 등록·수정·삭제부터 새 평가표 작성까지: 참여자를 포함해 한 사용자 흐름으로 재검수. 기존 사업장 사용 검증과 구분합니다.
3. 오류·경계 상황: 동시 저장, 장문·여러 위험 항목, 새로고침·뒤로가기, 삭제·복원을 같은 최신 환경에서 통합 검수합니다. 개별 자동 검사 통과와 구분합니다.
4. 실제 AI: 서버 사용량·토큰 계수 지원 답변 및 호출 재개 합의 후 텍스트·사진·음성 연결, 실패·재시도·모드 전환을 검증합니다. 현재 중단을 유지합니다.
5. 배포 환경: 실제 도메인·메일·한글 폰트 설정 후 휴대전화 QR, 다른 기기에서 공유 접속, 모바일 화면·PDF 출력 배치를 최종 검수합니다.

이번 PDF 확인은 다운로드와 텍스트·구조 검사입니다. 모든 페이지의 시각적 잘림과 인쇄 배치 검수는 별도로 남습니다.
실제 7일 경과를 기다리는 시험은 하지 않았습니다. 만료 조건은 관련 자동 테스트 범위입니다.
화면설계서 37~41쪽 부록은 계속 제외합니다.

추가 PDF 비교 검사도 통과했습니다. 서명 후 소유자 PDF에는 합성 서명 이미지 2개가 포함되고, 공유 PDF에는 서명 이미지가 없습니다. 두 문서의 참여자 이름과 현재 상 / 예상 중 내용은 유지됩니다. 서명 후 소유자 문서는 `.venv/review-signed-owner.pdf`에 보존했습니다.

# 로컬 화면 검수 안내 (AI 호출 없음)

## 목적과 준비 상태

현재 통합 코드의 화면·DB 저장·공통 위험도 계산·문서·서명·공유를 확인합니다.
AI 모델 품질, 사진 인식, 음성 인식 검증은 이번 범위가 아닙니다.

- 작업 폴더: `07_실험과_개발/SafeT-final-integration`
- 검수 DB: 로컬 MariaDB의 `safet_local_review`. 기존 테스트 DB는 보존했습니다.
- 계정: `review@test.invalid`. 비밀번호는 `.venv/local-review-login.txt`를 메모장으로 여세요.
- 가상 사업장: `화면 검수용 음식점`, 보유기기 `튀김기`.
- 기준 모드: `catalog_v1`. 실제 AI 대신 DB 기준으로 항목을 만들고 공통 정책으로 계산합니다.
- 전용 실행기는 실제 AI 주소를 로컬 차단 주소로 덮어쓰고 키를 비웁니다. 원래 서버 설정은 보존합니다.
- `.env`, 로그인 파일, 실행 로그는 Git에 올리지 않습니다. 이번 설정 전 `.env`는 `.venv/env-before-local-review.backup`에 보존했습니다.

## 처음 열기

1. 파일 탐색기에서 위 작업 폴더를 엽니다. 다른 SafeT 폴더로 들어가지 마세요.
2. `.venv/local-review-login.txt`를 메모장으로 열어 로그인 정보를 확인합니다. 설정 파일을 수정할 필요는 없습니다.
3. 브라우저에서 http://localhost:8000/pages/login.html 을 엽니다. HTML 파일을 더블 클릭해서 열지 마세요.
4. 검수 계정으로 로그인합니다. 사업장 관리에서 검수용 음식점과 튀김기가 보이는지 확인합니다.
5. 내 평가표에서 작성 중 평가표를 열거나 새 평가표를 작성합니다.
6. 새로 만들 때 기본정보에 작성자와 참여자 이름을 넣고, 현장 설명에 `튀김 조리 작업`을 입력합니다. 사진·음성은 생략합니다.
7. 보유기기를 확인하고 초안을 만듭니다. 이 초안은 AI 결과가 아니라 기준 데이터로 만든 검수 자료입니다.
8. 초안의 위험 항목을 눌러 현재 조치와 개선대책을 확인합니다. 아래 순서대로 검수합니다.

서명·공유는 내 평가표 카드에서 열 수 있습니다. 결과 화면 주소를 직접 입력하기보다는 화면의 버튼으로 이동하세요.

## 재실행과 종료

이미 서버가 켜져 있다면 다시 실행할 필요가 없습니다.
PC 재시작 후에는 Docker Desktop을 켜고 PowerShell에서 작업 폴더로 이동한 다음 실행합니다.

```powershell
# DB 컨테이너가 꺼진 경우에만 실행합니다.
docker start safet-risk-v2-test-20261117
powershell -ExecutionPolicy Bypass -File .venv/start-local-review.ps1
```

이 실행 창은 검수 중 열어 두세요. 직접 실행한 서버는 Ctrl+C로 종료합니다.
준비 과정에서 백그라운드로 실행한 서버는 아래 명령으로 종료합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .venv/stop-local-review.ps1
```

DB 컨테이너는 다른 로컬 테스트에서도 사용하므로 종료·삭제하지 않습니다.
현재 실행기는 기존 `SafeT-pr10-catalog/.venv`의 Python을 재사용합니다. 그 폴더를 삭제하지 마세요.

## 검수 체크리스트

문제가 있으면 단계, 클릭한 버튼, 기대 결과, 실제 결과를 기록하세요. 확정 전 수정 검사를 먼저 마칩니다.

| 확인 | 단계 | 기대 결과 |
|---|---|---|
| [ ] | 초안 생성 | 사진 없이 텍스트로 생성되고 새로고침 후 내용이 유지됨 |
| [ ] | 현재 조치 미확인 | 확인하지 않은 상태를 임의로 하 등급으로 처리하지 않음 |
| [ ] | 튀김 항목: 현재 조치 없음 + 전체 확인 후 저장 | 현재 위험도 상 표시 |
| [ ] | 같은 항목: 현재 조치 모두 선택 + 전체 확인 후 저장 | 현재 위험도 중 표시 |
| [ ] | 다시 현재 조치 없음, 개선대책 모두 선택 후 저장 | 현재 상을 유지하고 예상 중 표시. 실제 개선 완료로 표시하지 않음 |
| [ ] | 저장 전·후 | 예상 위험도는 저장 후 반영되고 새로고침 후 유지됨 |
| [ ] | 필수값 누락 | 담당자·예정일 등 누락 안내. 보완 후 확정 가능 |
| [ ] | 확정 | 확인 창 이후 결과 화면으로 이동. 확정 자료의 임의 수정 방지 |
| [ ] | PDF 다운로드 | 파일이 열리고 한글·사업장·날짜·조치·현재/예상 위험도가 화면과 일치 |
| [ ] | 참여자 서명 | 등록 참여자 서명 저장, 중복 서명 방지, 전원 서명 상태 반영 |
| [ ] | 공유 발급 조건 | 전원 서명 전 공유 제한, 완료 후 링크와 QR 발급 |
| [ ] | 공유 열기 | 같은 PC의 시크릿 창에서 링크로 결과 접근·다운로드 가능 |
| [ ] | 공유 중지·재발급 | 중지한 링크 차단, 재발급한 링크 정상 작동, 이전 링크 차단 |
| [ ] | 삭제·휴지통 (별도 미확정 평가표) | 삭제 후 휴지통 이동, 복원 후 내용 유지. 확정 자료는 삭제 제한 |

위 상→중 예시는 튀김 항목에 대한 기대값입니다. 모든 위험요인이 대책 선택만으로 하가 되는 것은 아닙니다.
현재 로컬 공유 주소는 localhost이므로 휴대전화 QR 접속은 검수 대상에서 제외합니다. 다른 기기 검수는 별도 네트워크 설정이 필요합니다.
회원가입·메일 발송은 설정하지 않았으므로 준비된 계정을 사용합니다.
화면설계서 37~41쪽 부록은 이번 검수·구현 범위에서 제외합니다.

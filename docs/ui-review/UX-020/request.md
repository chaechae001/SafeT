# UX-020 요청 · 2026-11-22

## 요청 원문
> 실제 휴대폰, 글자 크기 최대 설정 세팅해줘.
> 결과서 PDF도 우리솔루션에 맞게 개선하고, 모바일에서 보기 편하게 개선해줘.
> 평가표 초안 카드 리스트에서도 바로 삭제할 수 있게 해줘

## 해석
- **카드 삭제**: '평가표 초안 카드 리스트'는 03 내 평가표의 작성 중(초안) 카드로 본다. 초안 화면 안의 위험 항목 카드는 UX-015에서 이미 편집·밀어서 삭제가 있다.
- **결과서**: Safe-T 디자인(UX-019)과 같은 색·구성으로 바꾸고, 휴대폰에서 읽기 쉽게 한다.
- **휴대폰·글자 크기**:
  - 실기기로 접속해 확인할 환경을 만든다.
  - 안드로이드 '글자 크기' 설정의 130%와 최대 200%에서 화면이 깨지지 않게 점검하고 고친다.

## 관찰 근거
- 결과서는 A4 가로에 10칸 표, 본문 8.6pt다. 휴대폰 폭(390px)에 맞추면 본문이 약 4px로 보인다.
- 일반 평가표(`catalog_rls_v1`)는 법령을 `eval_dtl.law`가 아니라 `catalog_state.risk_law.law`에 저장한다. 그래서 결과서의 '관련 법령' 칸이 모두 '—'였다(1718에서 확인).
- 이 PC의 Windows 방화벽에 python.exe 수신 차단 규칙(개인·공용)이 있다. 관리자 권한도 없다.

## f 서명 처리·보관(변경 없음, 코드·DB 확인)

- 화면: 서명 칸(canvas)에 그린 획을 흰 바탕 PNG로 만들어(`sign.js` `exportPng`, 칸 크기 그대로) `data:image/png;base64,…` 문자열로 보냄.
- 서버: PNG 형식·크기(데이터 URL 30만 자 이하)를 검사하고(`schemas/sign.py`), `eval_sign` 테이블 한 행에 저장 — 평가표·참여자 번호, 이름, 서명 이미지(`sign_img`, LONGTEXT에 base64 그대로), 확인 체크, 서명 시각, 입력자. 로컬 DB 평균 약 9KB/건. 별도 파일·외부 저장소는 쓰지 않음.
- 규칙: 참여자당 1회, 정정 불가(다시 저장하면 409). 전원 서명하면 평가표 상태 확정 → 서명 완료, `sign_end_dt` 기록.
- 노출: 서명 조회 API는 이미지를 돌려주지 않음. 결과서 PDF(작성자 본인)에만 이미지를 넣고, 공유 링크 PDF에는 이미지 없이 서명 여부·시각만.
- 삭제: 휴지통에서 30일이 지나 영구 삭제될 때 평가표와 함께 `eval_sign` 행도 삭제.
- 확인 필요(팀 결정): 서명 이미지 암호화·보존 기간·접근 기록은 현재 없음.

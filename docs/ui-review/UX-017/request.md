# UX-017 요청 · 2026-11-22

## 요청 원문
> 1. 필수 고지 4가지가 들어있는 지 확인하고, 없으면 추가하고 있으면 너가 말한대로 작업 진행해.
> 2. 확정화면에서도 서명 열수있게 진행해.
> 3. 기기 직접 추가할 수 있게 하고, AI 계산이 그 값을 쓰게 해줘.
> 4. 진행해줘. (내 평가표 카드 위험항목 N건 — 목록 API에 항목 수 필드)
> 5. 핸드폰을 USB와 연결해서 하는게 아니라, 그냥 배포서버에서 확인하게 해줘.
> 6. 배포 서버 반영해줘.
> 작업 후 그다음에 개선하면 좋을 것들을 너가 추천해줘.

## 대상 화면·상태
- 01 login.html `#v-signup` → `#terms` 개인정보 안내 창
- 06 result.html `#v-list` 하단 버튼(확정 C 상태)
- 04 write.html `#v-equipment`(03 기기) + 새 창 `#eq-add`
- 03 home.html 평가표 카드 메타 줄

## 문제로 판단한 이유(관찰)
- 개인정보 창에 수집 항목만 있고 이용 목적·보유 기간·거부 권리와 불이익이 없음(4가지 중 1가지만 있음).
- 06 서명하기는 UX-016에서 이미 구현돼 있었으나 HTML 설계 주석이 "카드에서만"으로 남아 있음.
- 03 '기기 직접 추가'가 사업장 관리로 이동해 작성 중 입력이 사라짐. 초안 생성 요청(`CreateAssessment`)에 기기 칸이 없음.
- 목록 응답(`EvalCard`)에 항목 수가 없어 카드에 위험 항목 수를 못 보여 줌.

## 통과 조건
- 개인정보 창에 4가지가 보이고 320~390px에서 가로 넘침 없음, 체크 상태는 바뀌지 않음.
- 확정 화면 `서명하기` → 같은 평가표 서명 화면.
- 03에서 페이지 이동 없이 기기를 추가·빼기, `총 N개` 반영, 요청에 기기가 실리고 저장·검색에 쓰임. 사업장 기기는 그대로.
- 카드에 `위험 항목 N건`이 실제 항목 수와 같음.

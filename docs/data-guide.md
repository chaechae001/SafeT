# 데이터와 모델 관리

작성일: 2026-11-13, Asia/Seoul.

## 저장 위치

| GitHub에 보관할 항목 | 외부 저장소에서 관리할 항목 |
|---|---|
| 전처리·실험 코드와 설정 | 기업 원본과 식별 가능한 현장 자료 |
| 데이터 출처·버전·해시·준비 방법 | 실제 매장 사진·영상·음성 |
| 공유 권한을 확인한 소량의 예시 | 모델 가중치·어댑터·체크포인트 |
| 검증 결과와 한계 요약 | 대용량 결과와 실행 로그 |

현재 데이터·모델의 팀 공유 위치와 접근 권한은 이 작업에서 확인하지 않았다.
Cloud 경로나 모델 캐시가 모든 팀원에게 존재한다고 가정하지 않는다.
실제 입력 파일 목록은 [기존 AI 실험 안내](../ai/experiments/README.md)를 확인한다.

## 재현과 평가

원본은 보존한다. 파생 데이터는 별도 위치에 저장한다.
출처, 수집일, 이용·공유 권한, 전처리 명령, 버전과 해시를 기록한다.
학습·개발·평가 분리와 중복·누락·데이터 누출 여부를 확인한다.
합성 데이터, AI 보조 정답, 전문가 검수와 독립 현장 평가를 구분한다.
안전 기준이나 합격 점수를 임의로 만들지 않는다.

## 커밋 전 확인

.env, API 키, 토큰과 비밀번호를 커밋하지 않는다.
환경변수가 필요해지면 비밀 값이 없는 .env.example만 추가한다.
.gitignore는 이미 커밋한 파일을 보호하거나 비밀정보를 검증하지 않는다.

data/, uploads/, models/와 생성 결과는 기본 제외한다.
실험 입력인 frozen/, references/도 기존 제외 규칙을 유지한다.
이미지·영상은 기본 제외한다.
화면용 공개 이미지가 필요하면 공유 권한을 확인한 뒤 해당 파일만 명시적으로 허용한다.

가상환경과 프런트엔드 빌드 결과는 커밋하지 않는다.

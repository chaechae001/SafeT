# 백엔드

상태: 안내만 준비했다. 실행할 API 서버와 확정 기술 스택은 없다.

담당 범위 초안:
- 사용자·매장 권한 검사.
- 업로드 파일 관리와 AI 분석 요청 연결.
- AI 원본 응답과 사용자 검토·수정 결과의 구분 저장.
- 개선 이력과 변경 이력 관리.

매장별 접근 권한은 모든 관련 요청에서 확인한다.
파일 업로드에서는 허용 형식과 크기를 검증한다. 구체적인 제한은 팀에서 정한다.
AI 호출 실패·대기·정보 부족을 구분한다. 실패를 정상 분석으로 저장하지 않는다.
API 키와 파일 저장소 자격증명을 프런트엔드로 전달하지 않는다.

연결 전 [데이터 형식 초안](../contracts/README.md)을 팀과 확정한다.
실제 코드를 추가할 때 실행 명령, 의존성, 환경변수와 데이터베이스 준비 방법을 기록한다.

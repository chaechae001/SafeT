# C 법령 규칙 보강: 일반 조항·원인 불일치 조문 제외 (2026-11-20)

> 상태: 확인용 독립 모듈. 제외 목록(`risk_topics.json` → `exclude`)과 정답 세트는 검토 전 초안이다. 법령 결과는 후보이며 적용 판단은 담당자가 한다.

## 1. 발견한 문제

- 테스트 화면에서 '식용유에 착화되어 화재'(FOOD-04-C1) 위험요인에 산업안전보건기준에 관한 규칙 제325조 **정전기로 인한 화재 폭발 등 방지**가 법령으로 붙었다.
- 제325조는 인화성 액체·분진 설비의 정전기 불꽃을 막는 조문이다. 식용유 과열로 불이 붙는 주방 화재와 원인이 다르다.

## 2. 원인

- C는 B(KURE 검색) 후보 6개 중 위험유형 주제어가 맞는 첫 후보를 고른다. 주제어는 '화재'처럼 주제만 보고 원인(정전기인지 과열인지)은 구분하지 않는다.
- 이 카드의 B 후보 6개는 처음부터 약했다: 제325조(정전기), 화재예방법 제3조(국가와 지방자치단체 등의 책무), 과징금, 식품위생법 벌칙, 보험 가입, 고열·폭염장해. 앞의 두 개가 주제 확인을 통과했다.
- 이 카드는 A(카드 연결)가 더 맞았다(화재예방법 제17조 화재의 예방조치 등).

## 3. 검토한 대안 (정답 세트 25문항, 검토 전)

| 규칙 | 식용유 화재 | 1순위 정답률 | 정답 불분명 입력에 법령 부착 |
|---|---|---|---|
| C (이전) | 정전기 ❌ | 0.64 | 0.4 |
| A가 있으면 A, 없으면 C | 화재의 예방조치 | 0.44 | 0.6 |
| C, 단 A가 B 후보 6개 안이면 A | — | 0.60 | 0.4 |
| **C + 일반·원인 조문 제외 (후보 6개)** | **확인 필요 또는 제236조** | **0.68** | **0.4** |
| C + 일반·원인 조문 제외 (후보 20개) | 제236조 | 0.68 | 1.0 ❌ |

후보를 20개로 넓히면 맞는 법령이 없는 입력에도 항상 법령을 붙여 안전성이 나빠져 6개를 유지했다.

## 4. 바꾼 것

| 파일 | 내용 |
|---|---|
| `risk_topics.json` | `exclude` 추가. `generic_titles`: 목적·정의·책무·벌칙·과태료·과징금·양벌규정·보험 가입·적용 범위. `cause_terms`: 정전기·아세틸렌·가스집합·용접·용단·발파·잠수·궤도·교량·터널·굴착·거푸집·비계·선박·항공 |
| `engine.py` | `law_excluded()` 추가. C(`_alt_topic`)가 일반 조항과, 입력 문장·카드 문구에 없는 원인 낱말이 제목에 있는 조문을 건너뛴다. 제외한 후보와 이유를 `excluded`로 응답 |
| `static/index.html` | C에서 제외한 후보와 이유(예: '정전기로 인한 화재 폭발 등 방지 — 원인 불일치(정전기)')를 펼쳐 볼 수 있게 표시 |
| `tests/test_engine.py` | 테스트 1개: 식용유 화재 카드에서 정전기·책무 조문 제외, 입력에 '정전기'가 있으면 정전기 조문 사용 |
| `benchmark/stats_abc.py` | `--cmp`로 비교 결과 파일 지정 |
| `abc-stats-20261120.md` | 발표용 통계를 보강 후 수치(v2)로 갱신 |

규칙은 특정 문항에 맞춘 것이 아니라 일반 원칙이다: 일반·제재 조항은 위험요인의 법령 근거가 아니고, 원인이 다른 조문은 쓰지 않는다.

- 서버에서 '조리 중 식용유에 불이 붙어 화재가 났어요'를 넣으면 식용유 화재 카드는 '주제가 맞는 후보가 없습니다 · 담당자 확인 필요'로 나온다. 입력 문장에 따라 KURE 후보 6개가 달라져, 이 문장에서는 6개 안에 맞는 조문이 없다.
- 검사: 키워드 방식 단위 테스트 23개 통과. 혼합 방식 10개는 이 PC에 패키지가 없어 건너뜀.

## 6. 한계와 다음 작업

- 규칙을 이 사례와 정답 세트를 보고 만들었으므로, 같은 정답 세트로 잰 0.68은 실제보다 좋게 나왔을 수 있다. 새 문항으로 다시 재야 한다.
- 원인 낱말은 부분 문자열로 찾는다. 목록에 없는 원인 조문(예: 특정 기계 전용 조문)은 걸러지지 않는다.

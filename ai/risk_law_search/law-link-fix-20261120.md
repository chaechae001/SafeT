# 카드–법령 연결 개선 기록 (2026-11-20)

> 상태: 확인용 독립 모듈 개선. 주제 사전(`risk_topics.json`)과 정답 세트(`benchmark/gold_v0.json`)는 AI 보조 초안이며 담당자 검토 전이다. 최종 법령 적용 판단은 담당자가 한다.

## 1. 발견한 문제

- 테스트 화면에서 "식칼이 떨어짐"(물체가 떨어짐)이 산업안전보건기준에 관한 규칙 제42조(추락의 방지, 사람이 높은 곳에서 떨어짐)에 연결됐다.
- 원인 두 가지
  1. `synonyms.json`의 `"떨어짐": ["추락"]`이 모든 "떨어짐"을 "추락"으로 넓혔다.
  2. 카드–법령 연결이 낱말·의미 점수만 봐서, 겉보기 낱말만 겹쳐도 주제가 다른 조문이 붙었다.
     - 예: 칼 작업 → 제632조(냉장실 등의 작업), 혼합기 끼임 → 제670조(농약원재료 방제), 날카로운 조리기구 → 도로교통법 교통안전수칙

## 2. 확인한 사실 (측정)

| 확인 | 결과 |
|---|---|
| 점수 기준을 올리면 되는가 | 아니다. 엉뚱한 연결의 키워드 점수(0.16~0.44)와 맞는 연결(0.2~0.57)이 겹친다. |
| 모델을 바꾸면 되는가 | 아니다. e5-small·e5-large·bge-m3·KURE-v1·bge-m3+리랭커 6개 구성 모두 칼 베임 입력에 제632조를 붙였다. |
| 출처 자료에 적힌 법령을 먼저 쓰면 되는가 | 부족하다. 검색 카드 105개 중 5개에만 조문까지 연결되는 출처 법령이 있다. |
| 기존 벤치마크로 이 문제가 보이는가 | 아니다. 맞는 법령이 불분명한 입력(`laws: null`)은 법령 정확도 계산에서 빠졌다. |

## 3. 바꾼 것

| 파일 | 내용 |
|---|---|
| `synonyms.json` | `"떨어짐": ["추락"]` 삭제, `"높은 곳": ["추락"]` 추가. 사다리 입력은 기존 `"사다리"`가 '추락'을 덧붙인다. |
| `risk_topics.json` (신규) | 위험유형별 조문 주제어 사전. 예: 떨어짐 → 추락·작업발판·사다리, 베임 → 칼날·보호구, 교통사고 → 배달·이륜·도로교통법 |
| `engine.py` | 카드–법령 연결 때 조문 제목·장절 제목에 카드 위험유형의 주제어가 있는 조각만 쓴다. 없으면 연결하지 않고 이유와 "담당자 확인 필요"를 표시한다. |
| `benchmark/bench.py` | 지표 추가: `nolaw_attached`(불분명 입력에 법령을 붙인 비율), `risk_law_given`(법령 표시 비율). 리랭커 경로에도 주제 확인 적용. |
| `tests/test_engine.py` | 회귀 테스트 2개: 식칼 카드 ≠ 추락 조문, 사다리 카드 = 추락 조문 유지, "식칼이 떨어짐" 검색에 '추락' 미추가 |
| `README.md` | 연결 규칙·도입 이유·한계 갱신 |

주제어 작성 시 주의: 부분 문자열로 찾으므로 '청소'(분진 장의 청소의 실시), '운전'(도로교통법 운전자 준수사항), '절단'(와이어로프의 절단방법)처럼 다른 뜻으로 겹치는 짧은 낱말은 넣지 않는다. 법령명 전체 인정(`laws`)은 도로교통법·화재/소방 법률만 둔다.

## 4. 결과

정답 세트 `gold_v0.json`(33문항, 검토 전) 기준. 전: `benchmark/results_20261120/`, 후: `benchmark/results_20261120_topic/`.

| 구성 | 위험요인 법령 정답률 | 불분명 입력에 법령을 붙인 비율 |
|---|---|---|
| K0 키워드만 | 0.40 → 0.44 | 1.0 → 0.6 |
| C1 e5-small(혼합) | 0.56 → 0.56 (정답 손실 없음) | 0.8 → 0.4 |

- 키워드 방식에서 검색 카드 105개 중 8개(칼·깨진 그릇 베임 등)가 '연결 없음 · 담당자 확인 필요'로 바뀌었다.
- 국솥 국물 튐(Q24)은 키워드 방식에서 오답 → 제254조(화상 등의 방지) 정답으로 바뀌었다.
- 검사: 키워드 방식 단위 테스트 16개 통과, `ai/experiments` CPU 자체 검사 3개 통과. 혼합 방식 단위 테스트 10개는 이 PC에 임베딩·Chroma 패키지가 없어 건너뜀(혼합 방식은 C1 벤치마크로 확인).
- C2~C5는 수정 후 다시 측정하지 않았다.

## 5. 남은 문제

- 주제는 맞지만 법령이 다른 연결은 못 막는다: K급 소화기 → 소방시설법 제11조(자동차에 비치하는 소화기), 식기세척기 컨베이어 끼임 → 제193조(낙하물에 의한 위험 방지).
- 위쪽 자유 "법령 검색"에는 위험유형이 없어 주제 확인이 적용되지 않는다. "식칼이 떨어짐" 검색 시 화물의 낙하 방지 등 무관한 조문이 여전히 나온다.
- 카드 선택 오류로 생기는 법령 오류는 별개다(예: 고무장갑 습진 입력 → 넘어짐 카드 → 작업장의 바닥).
- 위험유형이 여러 개인 카드는 그중 하나만 맞아도 통과한다(예: 베임·떨어짐 카드 → 작업발판 등).

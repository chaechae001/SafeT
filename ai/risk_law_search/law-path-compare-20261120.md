# 법령 찾기 방식 비교: A(현재) · B(#45 방식) · C(B+주제) 기록 (2026-11-20)

> 이후 갱신: C를 서버 기본 법령으로 정했고(`--law c`), C에 일반 조항·원인 불일치 조문 제외 규칙을 더해 1순위 정답률이 0.64 → 0.68이 됐다. [보강 기록](c-rule-fix-20261120.md), [발표용 통계 v2](abc-stats-20261120.md). 아래 `--law-alt kure45` 옵션은 `--law c`(기본)로 바뀌었다.

> 상태: 확인용 독립 모듈의 비교 실험. 정답 세트(`benchmark/gold_v0.json`)와 주제 사전(`risk_topics.json`)은 AI 보조 초안이며 담당자 검토 전이다. 어느 방식을 서비스에 쓸지는 팀 결정 사항이다.

## 1. 배경

- PR #45(`ai/legal_review`)가 평가표 저장 흐름에 법령 근거 검색(KURE-v1 검색 + EXAONE 판정)을 붙였다.
- 우리 모듈도 나중에 서비스 화면에 연결할 예정이라, 위험요인은 우리 모듈로 찾고 법령 찾기만 바꿨을 때 어느 쪽이 나은지 비교하기로 했다.
- 기존 방식(A)은 지우지 않고, #45를 참고한 경로(B)와 조합(C)을 옆에 만들어 같은 입력으로 비교했다. #45 브랜치는 수정하지 않았다.

## 2. #45 확인 사항 (코드 기준, 실행하지 않음)

- 임베딩: KURE-v1, 첫 토큰(CLS) 벡터 정규화, 최대 512토큰, 접두어 없음. 임베딩 점수만 사용.
- 검색: Chroma 컬렉션 `baseline-kure-6258660a191f`(L01, 청크 정확히 267개) 전체 순위 → (법령, 제N조) 중복 제거 → 상위 6개 → EXAONE 근거 판정.
- 질문: 작업 + 위험요인 제목 + 원인(+ 근거 문장).
- 인덱스를 만드는 청킹·임베딩 코드는 #45에 없다. L01의 법령 구성은 저장소에서 확인할 수 없다.
- 법령 검색이 실패하면 평가표 저장이 503으로 막힌다(`SAFET_LEGAL_PYTHON` 설정 시).

## 3. 비교한 세 방식

| | A. 카드 연결(현재) | B. #45 방식 | C. B+주제 확인 |
|---|---|---|---|
| 위험요인 | 우리 analyze | 같음 | 같음 |
| 법령 찾기 | 카드–법령 자동 연결 + 위험유형 주제 확인 | 질문(입력 단위 문장 + 카드 제목 + 카드 본문) → KURE-v1 검색 → 상위 6개 | B 후보 6개 중 카드 위험유형과 주제가 맞는 첫 후보, 없으면 '확인 필요' |
| 법령 원문 | `docs/chroma` hwpx | 같은 hwpx, 시행 중 조각 3,406개를 KURE로 새로 임베딩 | B와 같음 |
| AI 판정 | 없음 | 없음(#45의 EXAONE 판정은 실제 모델 호출 중단 상태라 제외) | 없음 |

B는 #45의 검색 규칙을 재현했지만 원문이 L01이 아니라 우리 hwpx다. 결과는 '#45 검색 방식'의 성능이며 '#45 L01 인덱스'의 성능이 아니다.

## 5. 결과

정답 세트 30문항(검토 전), 위험요인은 keyword 모드 analyze, 법령 지표는 첫 위험요인 기준. 결과: `benchmark/results_20261120_45cmp_c/compare_45.json`.

| 방식 | 1순위 정답률 (25문항) | 정답 불분명 입력에 법령을 붙인 비율 (5문항, 낮을수록 좋음) |
|---|---|---|
| A. 현재 | 0.44 | 0.6 |
| B. #45 방식 | 0.56 | 1.0 (항상 붙임) |
| **C. B+주제** | **0.64** | **0.4** |

- B 상위 6개 안에 정답이 있는 비율: 0.88. #45의 AI 판정이 이 6개 중에서 고르므로 AI 판정의 상한이다(측정하지 않음).
- 처리 시간: B·C를 켜면 입력 하나에 평균 약 1.6초(CPU). A만 쓸 때는 수 ms.
- 참고: A를 혼합 모드(e5-small)로 측정한 값은 0.56이다(`results_20261120_topic/C1.json`). 이번 비교는 테스트 화면과 같은 keyword 모드다.

## 6. 한계

- 정답 세트가 25문항(법령 정답 있는 것)이라 한 문항이 0.04다. Q04(가스)처럼 정답이 '액화석유가스법 아무 조문'인 문항은 B의 '벌칙' 조문도 정답으로 처리됐다.
- B·C는 #45의 L01이 아니라 우리 원문을 썼다. #45 실제 결과와 다를 수 있다.
- AI 판정 단계를 측정하지 않았다. B의 최종 성능은 AI 판정에 따라 달라진다.
- C는 B 후보 6개 안에서만 고른다. 6개 안에 주제가 맞는 오답이 있으면 그대로 고른다(Q28 냉동창고 → 고열작업 등).
- 청크 본문 형식('법령명 조문위치 조문제목' + 원문)은 #45 L01을 추정한 것이다.

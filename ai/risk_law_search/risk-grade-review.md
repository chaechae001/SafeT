> **2026-11-21 갱신**: 이 판정표(FOOD-3LEVEL-1.2)는 신규 실제 평가표에 적용됐다. 기준 문서: [위험도 합의 문서](../../docs/implementation/risk-development-agreement.md). 내부 검토 화면은 실제 평가표와 같은 판정 함수와 같은 카탈로그(`contracts/catalog_risk/catalog-food-3level-1.2.json`)를 쓴다. 시나리오 미연결은 임시 상 대신 판단 필요로 표시한다.

#44 기반 로컬 구현 · FOOD-3LEVEL-1.2

분석 결과 카드의 제목 행에서 태그와 관련도 사이에 위험도 신호등 하나를 표시합니다. 빨강은 상, 노랑은 중, 초록은 하입니다. 화면 읽기 도구에는 ‘위험도 상·중·하’ 중 해당 등급을 전달합니다. 검토 서버에서는 신호등 옆의 **(테스트)**를 누르면 같은 카드와 시나리오가 새 탭에서 열립니다.

## 언제 계산하나요?

- 분석할 때 카드에 연결된 시나리오와 확인된 조치 0개를 기준으로 위험도를 계산합니다.
- #44의 현재·개선 조치 체크리스트는 카드의 선택 항목입니다. 이 화면에서 체크를 바꿔도 제목의 위험도는 그대로입니다.
- 예상 위험도는 서버의 `POST /api/risk-grade`에서 시나리오 기준의 현재·계획 조치 ID를 받아 계산합니다. 아래 예상 등급은 이 API의 결과입니다.

## 어떻게 판정하나요?

| 시나리오의 예상 피해 | 핵심 조치 일부 또는 전부 미확인 | 핵심 전부 충족, 보완 일부 미확인 | 전체 충족 |
|---|---|---|---|
| 경미·응급처치 | 중 | 하 | 하 |
| 휴업 부상·질병 가능 | 중 | 중 | 하 |
| 사망·중상 가능 | 상 | 중 | 중 |

예를 들어 튀김 중 기름 튐은 초안 **중**입니다. 온도 제어, 냉각 후 배유, 수분 유입 방지와 보호구까지 네 항목을 체크하면 예상 **하**입니다. 화재는 초안 **상**이고 핵심 조치를 모두 충족하면 예상 **중**입니다. 시나리오 미연결은 **판단 필요**로 기록합니다(담당자 검토).

음식업 사고와 조치 후보는 고용노동부·안전보건공단의 [음식업 재해사례 중심 위험성평가 안내서](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=15816)를 참고합니다. 테스트 결과의 문헌 ID와 인쇄본 쪽수는 시나리오별 참조이며, 등급 경계는 팀의 서비스 기준입니다.

**상·중**은 감소대책 대상이고 **하**는 조치를 유지하는 수준입니다. 이 표는 서비스 판정 기준입니다. 현장 검토 전이며 현장 정확도는 별도 평가 대상입니다.

## 무엇이 내부에 남나요?

개발 서버는 계산 시각, 카드·시나리오 ID, 단계, 정책 버전, 결과, 피해 수준, 조치 충족 구간, 현재·계획 조치 ID, 미충족 핵심 조치, 문헌 참조와 판정 이유를 SQLite에 기록합니다. 설명을 보고 등급을 수동 변경하는 UI는 제공하지 않습니다. 기록 위치는 SAFET_RISK_AUDIT_DB로 지정할 수 있고 기본값은 사용자 홈의 .safet/risk-assessments.sqlite3입니다. 평가표별 이력과의 연결은 이번 로컬 검토 범위 밖입니다.

## 팀원 테스트 · Python 3

1. 이 작업본의 저장소 루트에서 아래 명령을 실행합니다. 각자 PC에서 실행할 수 있습니다.

   ```bash
   python -m ai.risk_law_search.server --host 127.0.0.2 --port 8020 --mode keyword --law a --risk-test
   ```

2. [일반 화면](http://127.0.0.2:8020/)에서 **예시 넣기 → 분석 → 신호등 옆 (테스트)**를 누릅니다. 새 탭에서 카드 ID와 선택된 시나리오를 확인합니다. 미연결 카드는 판단 필요로 열립니다.
3. **재료 투입·기름 취급 중 고온 기름이 튐**을 선택합니다. 미선택 시 위험도 중, 핵심 충족률 0/3입니다. 핵심 세 가지를 체크하면 3/3이고 예상 중입니다. 보호구까지 선택하면 예상 하입니다. 같은 항목을 양쪽에 체크해도 한 번만 집계됩니다.
4. 판정 결과에서 남은 핵심 조치와 문헌 쪽수를 확인합니다. **판정기 검증**의 일치율은 기준표와 결과가 일치한 조합 수 ÷ 검사 조합 수입니다. 전문가 평가와의 일치율은 별도 측정 대상입니다.

자동 검사 명령은 `python -m ai.risk_law_search.tests.check_grade_combinations`입니다. 일반 실행 시 `--risk-test`를 생략하면 버튼과 테스트 경로가 비활성화됩니다.

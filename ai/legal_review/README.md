# 법령 근거 추적과 자체 모델 평가

질문을 KURE-v1으로 검색하고 실제 후보 원문을 8010에 전달한다. 후처리 결과를 최종 출력으로 저장한다. `SAFET_LEGAL_EVALUATOR_ENABLED=true`이면 같은 8010 관문에서 근거 일치를 평가한다.

## 실행 환경

Python 3.11 환경에 백엔드 요구 패키지와 ChromaDB, PyTorch, Transformers, LangSmith를 설치하고 KURE-v1 가중치 폴더를 준비한다.

- `SAFET_AI_GATEWAY_URL`, `SAFET_AI_API_KEY`, `SAFET_AI_MODEL`은 기존 모델 관문 설정이다.
- `SAFET_LEGAL_WEIGHTS`, `SAFET_LEGAL_CHROMA`는 KURE-v1과 전문 인덱스 저장 폴더다.
- `LANGSMITH_TRACING=true`, `LANGSMITH_API_KEY`, `LANGSMITH_PROJECT`는 추적 프로젝트 연결 설정이다.
- `SAFET_LEGAL_TRACE_DIR`을 지정하면 질의별 JSON도 저장한다.
- 생성과 평가에 같은 모델을 사용한다. 검색 점수와 생성 모델 선택을 독립적으로 비교한다.

## 기록 필드

루트 실행 `Legal RAG`에서 `inputs.question`을 읽는다. `outputs.source_documents`는 생성 모델에 실제 전달한 법령 후보이며, `outputs.raw_answer`는 생성기 원응답, `outputs.answer`는 후처리 후 최종 구조화 출력이다. `outputs.evaluation`은 자체 모델의 채점 결과다. 생성과 평가의 LLM 하위 실행에 각각 토큰 수와 처리시간이 남는다.

`legal_groundedness_v1`은 원문 뒷받침, 질문 관련성, 적용 요건·예외, 위반 단정 여부, 보류 처리의 다섯 항목을 평가한다. 모든 모델 항목이 true이고 인용 무결성 검사도 통과하면 1점이다. 불일치는 0점이며 형식 오류·호출 실패는 점수 없음으로 기록한다. 인용 무결성은 청크 ID, 법령명, 조항, 원문 문장을 대조한다.

점수와 이유를 루트 실행의 `legal_groundedness_v1` 피드백에 연결한다. 점수는 최종 후처리 출력을 대상으로 한다. 검색 Recall·Precision·F1·Hit·MRR 및 원응답 자체의 품질은 별도로 측정한다. 평가 모델과 생성 모델이 같으므로 사람의 원문 대조를 함께 사용한다.

## 과거 실험 기록

원응답 JSON에서 질문·실제 후보·답변·모델·토큰·처리시간·원본 파일 해시를 가져온다. 가져온 실행에는 `historical_import` 태그를 붙이고 표시 시간은 가져온 시각이다. 당시 전체 처리시간은 `original_elapsed_seconds`에 보존한다. 당시 저장되지 않은 단계별 시간·평가 점수는 새로 만들지 않는다. 파일 해시와 문항에서 만든 고유 ID로 중복 가져오기를 방지한다.

## 법령 전문 인덱스 구축

저장소 루트에서 검수용 Python으로 실행한다. SAFET_LEGAL_CHROMA는 완료된 manifest.json이 있는 폴더를 가리킨다. 기존 L01 발췌 인덱스와 구분해 새 폴더를 사용한다.
생성된 `manifest.json`에는 문서별 파일명·원본 해시·청크 수가, `chunks.jsonl`에는 청크 ID·법령명·조항 위치·파일명·원본 해시가 담긴다. 서비스는 목록을 적재 결과와 대조한다. 생성된 DB와 모델 가중치는 로컬 또는 팀의 인덱스 저장소에 둔다.

```powershell
python ai/legal_review/full_index.py chroma/laws <새-인덱스-폴더> <KURE-v1-가중치-폴더>
```

파일 번호 01, 02, 03, 04, 05, 06, 06-02, 07, 08을 각각 우선순위 1~9로 변환한다. 각 벡터에는 법령명·위치·제목·원문을 넣고, 메타데이터에는 원본 파일명·SHA-256·우선순위·청크 ID를 보존한다. 문서별로 최대 8개씩 검색한 뒤 코사인 유사도에 0.002 × (9 − 순위)를 더하고, 같은 법령·항의 중복을 제거해 상위 6개를 모델에 전달한다. 가산점은 초기 설정이며 실측 최적값은 미정이다.

각 파일의 조문과 부칙 텍스트를 읽는다. 삭제로 표시한 조문은 검색에서 제외한다. 원본 밖의 별도 첨부물이나 이미지 OCR, 개정 이력에 따른 시점별 법 해석은 지원 범위 밖이다. 규칙 적용 범위 밖에서 모델이 고른 후보는 수동 검토로 표시한다.

### 전문 인덱스 검수 · 2026-11-20

KURE-v1 GPU 임베딩 후 검수용 CPU 프로세스에서 Chroma를 다시 열었다. 본문 1,494조(삭제 표기 포함)와 부칙으로 3,901개 청크를 저장했다. 문서별 저장 ID·파일명·원본 해시를 확인했다. 각 문서의 원문 청크 하나를 검색어로 사용한 연결 검사에서는 9개 모두 자기 청크가 1순위였다.

기존 22회차의 자연어 질문 6개도 검색했다. 정답 조항이 지정된 4건 중 바닥 제3조제1항은 1위, 통로 제22조제3항은 5위, 분쇄기 제130조제1항은 1위였다. 빗길 도로교통법 제48조제1항은 상위 6개에서 누락됐다. 나머지 면허별 허용 범위·점검자 질문은 지정 정답 조항이 없어 이 지표에서 제외했다. 이번 수치는 검색 지표이며 8010 생성 답변은 재측정하지 않았다.

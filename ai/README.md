# AI 작업 영역

| 경로 | 용도 |
|---|---|
| [experiments/](experiments/README.md) | 기존 추론·학습·비교 실험과 재현 조건. |
| [src/](src/README.md) | 향후 서비스 연결용 코드. 현재 안내만 있다. |

실험 코드의 경로와 파일 이름을 유지한다.
파이프라인 실험은 이웃 폴더의 모델 비교 코드를 불러온다.
실험 코드를 바로 서비스 API로 취급하지 않는다.

서비스 연결 전에 모델, 입력, 출력, 오류 처리와 실행 환경을 확정한다.
GPU 모델 환경과 OCR 환경을 구분한다.
[루트 환경 기록](../261113_observed_environment_DR.json)은 관측 버전이며 설치용 lock 파일이 아니다.

학습 데이터, 평가 정답, 모델 가중치와 실제 이미지는 이 저장소에 포함하지 않는다.
합성 데이터와 AI 보조 정답을 독립 현장 검증으로 표현하지 않는다.

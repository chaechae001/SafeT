## 목적

- PR #53의 형태소 판정은 별도 검증셋에서 문맥이 필요한 사례를 놓쳤다.
  예: "전원을 안 켜요", "꺼 둡니다", "메뉴에 없습니다", "있긴 한데 안 써요", "그거 안 써요", "점심에는 안 쓰고 저녁에만 써요".

  모델 판정만으로 평가 행을 지우지 않는다.

모델 확인과 결합

- 모델 출력: `{"FRY": {"status": "used|unused|unknown", "quote": "..."}}`. 온도 0, 최대 200토큰, JSON schema 강제.
- 검증: status 값, quote가 입력에 그대로 있는지(공백 무시), quote에 대상 기기·작업어가 있는지 확인한다.
- 모델 판정이 규칙 잠정 판정과 같을 때만 확정한다. 다르거나, unknown이거나, 검증·호출에 실패하면 `작업 미확인`이다.
- 잠정 판정이 "사용"인 생략 주어 사례는 모델이 미사용이라 해도 제외되지 않는다.
- FRY 제외는 튀김 작업어(튀김·튀기다)의 진술일 때만 한다("기름 교체 중단"만으로는 제외하지 않음).

## 한계와 누출

- v2는 규칙 확장 전에 고정했다. 다만 A 결과를 본 뒤 규칙을 구현했고, B 결과를 보고 부품·대명사 규칙 1곳을 고쳤다.
  고친 문장: "전원 코드가 낡았는데 교체를 안 했어요"가 미사용 후보로 잡힌 것. 따라서 B·C 수치는 완전한 독립 평가가 아니다.
- 남은 미사용 놓침 21건(C)
  - 규칙이 "확실한 사용"으로 판정해 모델에 묻지 않은 문장들이다.
    예: "창고에 넣어 놨어요", "본사에서 완제품으로 받아서 데우기만 해요", "덮개 씌워서 보관 중", "놀리고 있어요", "못 쓰고 있어요".
  - STT 오류로 단서가 사라진 문장: 지웠습니다, 앉습니다, 5분만.
  - 이 문장들은 행이 생기고 사람이 확인하는 쪽(안전 쪽)이다.
- "튀길 때" 같은 활용형은 FRY 기준어에 없어 사진 후보로만 남는다(작업 미확인). 미사용 판정과 별개인 기준어 문제다.
- 모델이 사용 중인 작업을 미사용으로 답한 사례(주말에만 해요)가 있었다. 모델 판정만으로 제외하면 안 된다는 근거다.
- 백엔드 전체 흐름(`SAFET_NEGATION_JUDGE=exaone`)으로 평가표를 만드는 E2E는 실행하지 않았다. 평가는 검색 단계(`retrieve_with_evidence`)까지다.
- 모든 문장은 합성이며 현장 판정 정확도로 해석하지 않는다.

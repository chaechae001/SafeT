# 위험요인(시나리오 ID) 선택 정확도 평가 (2026-11-22)

입력 기반 평가표에서 어떤 위험요인 행(FRY·KNIFE·GRIDDLE·MIX·ENV 등)이 생기는지 확인한다.
RAG 법령 매칭과 위험도 등급 계산(`risk_policy`)은 이 평가 범위 밖이다.

## 평가 방식

`run_pipeline`을 서비스와 같은 순서로 실행한다(`batch_size=1`, `RAG_LINKS` EQ_FRYER burn→FRY·slip→ENV, 서비스 `extract()`의 ENV 인용 필터와 `build_context()`의 튀김기 추가 규칙 재현). 모델은 두 방식으로 모의한다.

- **greedy**: 모델에 전달된 후보를 모두 평가 행으로 고르고 입력 문장 하나를 인용한다. 11/22 실제 EXAONE에서 관측한 과선택 행태의 최악 조건이다. 규칙·후처리가 오탐을 얼마나 막는지 본다.
- **oracle**: 정답에 있는 후보만 고른다. 후보 단계와 후처리 때문에 생기는 누락의 상한을 본다.

재현: 저장소 루트에서 `python ai/experiments/261122_위험요인선택정확도_DR/261122_hazard_selection_eval_DR.py --label after` (검증셋은 `--gold <검증셋 경로>`).

# 신규 분석·평가

새로 진행할 데이터 탐색·모델 비교·RAG 평가와 결과를 관리합니다.

- 필요할 때 `notebooks/`, `scripts/`, `reports/`를 추가합니다.
- 기존 실험은 [ai/experiments](../ai/experiments/README.md)에 보존합니다. 이번 작업에서는 이동하지 않습니다.
- 서비스에서 실행할 AI 코드는 [ai/src](../ai/src/README.md)에 둡니다.
- 원본 데이터·모델 가중치·대형 결과는 외부에서 관리합니다.
- 데이터 출처·버전·실험 조건·지표·한계를 기록하고, 합성 자료와 독립 검증을 구분합니다.
- 세부 담당자는 작업별 Issue에서 정합니다.
